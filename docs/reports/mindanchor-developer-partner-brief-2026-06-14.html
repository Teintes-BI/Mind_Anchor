系统形态

MindAnchor 现在应被理解为“个人 Agent 操作层”，不是单一 App。App 负责采集和呈现；核心处理层负责事实、隐私、方法、兴趣、建议和反馈；Agent 平台只是可替换执行环境。

本地采集面

Collector / Client

负责权限、原始信号、用户记录、桌面状态和反馈按钮。原始高敏数据默认留在本地。

平台无关核心

MindAnchor Core

事实账本、上下文包、隐私钩子、方法插件、兴趣模块和主动性策略都在这里定义。

Agent 适配层

Adapter / Runtime

OpenClaw、Hermes、Codex 自动化或 MCP 工具都只能通过标准契约读取上下文、提交建议和执行动作。

下一阶段核心契约

开发者不应把新想法写成散落 prompt。它们需要变成可测试、可替换、可审计的对象。

RawSignal原始 OS、用户记录、兴趣和项目输入。
FactLedger带来源、置信度、时效和撤回能力的事实账本。
ContextPacket平台无关上下文包，不绑定 OpenClaw 或某个 App。
PrivacyHook最小化、假名化、密钥扫描和外发审计。
AgentAdapter把上下文发给 OpenClaw、Hermes、Codex 自动化或 MCP 工具。
FeedbackEvent有用、烦、不准、稍后、不再提醒，反向更新系统。
MethodPack 方法插件

哲学、心理学、积极心理学、幸福心理学、应用方法都要用 manifest 管理，声明适用场景、输入需求、输出风格和安全边界。

InterestModule 兴趣模块

把徒步、摩托、宠物、AI 新闻等主题做成可分享模块，包含信息源需求、试推策略、反馈指标和计划模板。

SourceConnectorRegistry 接口库

把微信公众号、天气、地图、搜索、OS 行为等分成通用源、专用源、私有源，并记录授权、刷新频率、合规风险和可服务主题。

WorkStyleProfile 工作方式画像

不同职业的专注状态不同。键盘频率、聊天、沟通、停顿必须结合职业、心情和任务上下文解释。

SanitizedContextPacket 可外发上下文

真正给大模型的只能是抽象事实、约束、目标和必要证据，不能包含原始可识别生活数据。

ModelEgressAudit 外发审计

每次模型调用必须记录目的、模型、字段类别、脱敏结果、风险决策和可撤回记录。

开发要求

新开发者最需要先接受这些要求。它们比“能不能跑通一个功能”更重要。

契约先行 先定义 schema，再写业务

新增模块必须先说明输入、输出、权限、失败模式和审计字段。没有 schema 的 prompt 不是稳定能力。

隐私默认本地 原始数据不默认外发

OS 行为、用户记录、对话、健康/经济/情绪等敏感信息先本地解释。外发必须经过 PrivacyHook。

可拒绝 任何主动建议都要能回退

稍后、忽略、不再提醒、认为不准，都必须成为可学习的反馈事件，而不是简单关闭弹窗。

平台无关 不要把能力写死在 OpenClaw

OpenClaw 是当前主 runtime，但核心概念要能迁移到 Hermes、Codex 自动化、MCP 或其它 agent 平台。

语义验收 链路通过不等于效果可靠

M7 的重点是模型语义质量。测试要覆盖“为什么现在提醒”“是否过度打扰”“是否正确降频”。

非临床边界 幸福支持不是医疗诊断

心理学/哲学模块只能做自我照护与行动支持；高风险情绪信号要转向现实支持和专业帮助路径。

边界与不要误解的地方

这些是新人最容易误判的点，建议在第一次讲解时直接说明。

不是普通 Todo

任务只是入口，真正目标是状态、事实、兴趣、价值和反馈闭环。

不是监控软件

采集必须服务于用户可控的恢复、提醒和反思，不服务于评价人格或绩效。

不是完整 SaaS

多用户、租户隔离、计费、支持和合规边界还没有产品化。

不是单一 Agent

OpenClaw 是当前主路径；核心应抽象成可迁移协议和适配层。

给开发者的第一判断

如果一个改动会增加采集能力，却没有同步增加授权、脱敏、审计、拒绝权和降频策略，它就不是合格的 MindAnchor 改动。这个项目的核心不是“更懂用户”，而是“在高度敏感的数据环境里仍然让用户保持控制权”。
