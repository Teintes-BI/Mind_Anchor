六、已打通的关键闭环

闭环 A：对话 authority handoff

  • 用户发送一句话。
  • Picard 判断是否需要 authority handoff。
  • Jarvis / Data 经 OpenClaw 路径被真正调起。
  • Gateway 执行动作并写回结果。
  • Mac 客户端通过 execution trail 看到本轮真实执行者。

闭环 B：memory governance

  • 用户说“请忘记我偏好短句这条记忆”。
  • Picard -> Data handoff 进入同一条 conversation trace。
  • 目标记忆被删除或撤销 recall。
  • 当前已召回 coach memory 被同步 revoke。
  • Mac GUI 上可以看到 Authority · Data 与 memory revoked。
最新关键修复： authority execution 已新增 includeReadModelRefresh 控制； conversation authority handoff 现在默认关闭阻塞式 read model refresh， 从而避免 governance turn 卡在 pending_full。
