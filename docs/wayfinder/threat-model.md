# Wayfinder 威胁模型

## 数据资产和边界

| 资产 | 可能风险 | P0 控制 | 删除/撤回 |
|---|---|---|---|
| 手动文字/短语音 | 误写成事实、模型供应商暴露 | 用户主动提交、结构化摘要、trace | 删除事件和派生候选 |
| 原始音频 | 旁观者录音、泄露、跨境传输 | P0 不收集；P1 只短滚动缓存，显式指示 | 摘要完成后删除 |
| 相机/眼镜画面 | 旁观者、敏感属性、人脸泄露 | P0/P1 禁用；P3 只用户主动短片段 | 处理后删除原图 |
| 桌面信号 | 工作隐私、错误推断 | 只采 active app/idle/lock/window category | 删除事件，不采正文 |
| 健康摘要 | 特殊类别数据、误诊 | P2 之前不启用；只聚合摘要和 missingness | 撤回权限并删除派生信号 |
| 目标/价值/选择 | 个人画像、模型操纵 | 分层记忆、版本化、只写已确认偏好 | soft revoke + 永久删除 |
| 模型输出 | 幻觉、prompt injection、越权执行 | 结构化 schema、evidence、policy gate | trace 审计，不能伪造成功 |
| 设备凭据 | 设备冒用、越权采集 | 每设备密钥、配对、撤销、心跳 | 立即 revoke |

## 攻击/失败场景

1. 外部语音或网页文本要求 agent 忽略策略：输入视为不可信数据，不能改变系统指令。
2. 重复或乱序音频 chunk：使用 `clientEventId`/幂等键，事件可重放但不重复创建。
3. 低置信度误听：只创建 `awaiting_confirmation` 候选，不创建 Task。
4. 用户撤回麦克风同意：新事件立即拒绝，临时原始媒体进入删除队列。
5. OpenClaw 不可用：返回 `pending/failed`，不生成伪造的 full response。
6. 高风险选项尝试自动执行：确定性 policy 阻断，必须前台二次确认。
7. 旁观者被录音：设备有可见/可听状态，公共场景默认不启动。
8. 记忆污染：模型推测进入 candidate，只有用户确认或多证据才影响长期建议。

## 验收证据

- 每类资产都有 consent、retention、revoke、delete 方案。
- 10 个 fixture 覆盖误听、越权、隐私和高风险场景。
- API 与 worker contract 测试证明高风险动作不能绕过 policy。
- 导出结果包含事件、选择、结果、trace 和撤回状态，不包含已删除原文。
