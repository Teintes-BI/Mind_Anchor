# Wayfinder 实施边界

Wayfinder 是 MindAnchor 上的用户掌舵式决策支持层。P0 只验证一条可回放的闭环：

`用户输入 -> 情境确认 -> 3 个可解释选项 -> 用户选择 -> 行动结果 -> 复盘`

## 阶段边界

| 阶段 | 允许能力 | 明确不做 |
|---|---|---|
| P0 | 手动文字、手动短语音、目标/价值关联、情境确认、A/B/C 选项、选择账本、每日复盘 | 持续监听、相机、健康数据、自动外部动作 |
| P1 | 桌面 active app/idle/lock、手机按键语音、现有 Coach/GoalFlow/Recovery/Reflection | 默认 24/7 录音、截图正文、键盘记录 |
| P2 | HealthKit/Health Connect 聚合摘要、低置信度能量线索、预测校准 | 医疗诊断、因果断言、强制休息结论 |
| P3 | 设备能力适配器、一个音频穿戴 spike、用户主动触发眼镜短片段 | 多厂商承诺、连续摄像、旁观者识别 |

## 风险等级

- `low`：整理、休息、个人任务顺序等可逆动作。
- `medium`：创建任务、调整计划、准备但不发送消息；必须用户确认。
- `high`：关系冲突、重大公开表达、财务/法律/医疗相关决定；只给分析和问题清单，禁止自动执行。
- `critical`：自伤/他伤、急症、违法规避、未成年人风险；停止普通建议，显示专业或紧急资源。

## 全局红线

1. 没有 `consentRef` 的事件不得进入情境生成。
2. 未确认的情境不得写入真实 Task 或触发外部工具。
3. 原始音频/视频默认不进入长期存储。
4. 任务、状态和健康事实以业务 Store/数据库为真相，不以 agent memory 为真相。
5. 所有模型输出必须带 `traceId`、来源、置信度、模型和技能版本。
6. 用户可以暂停、撤回、删除和导出每一个数据源及其派生记忆。

## 首个发布门

只有当 P0/P1 的 API、Web、OpenClaw stub 和 macOS 测试通过，且创建者本人连续使用 14 天、没有未处理高风险隐私事件时，才允许进入 P2。
